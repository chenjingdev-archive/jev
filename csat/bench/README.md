# Jev-like 지식 벤치마크 — 2027학년도 9월 모의평가 (2026-09-27)

Jev와 Jev-like 6개를 같은 조건에서 시험했다. 설계와 규칙은 `PROTOCOL.md`에 있다. 나중에 나온 8개(d1, Nimble, Tev1 두 모델, Jeff 세 모델, Julia-1)는 아래 '추가 시스템' 절에 있다. 2026-10-25에 더한 OpenAI Decisions API와 Jev 1.14.0은 그다음 두 절에 있다.

- 모든 모델은 같은 텍스트 입력(`canonical-2027-09.json`, sha256 `9b5f8f17…`)을 받는다.
- 지시문은 하나로 고정했고, 호출 형식은 `choose(state, instructions, criteria)` 하나다.
- 보기 순서를 5가지로 바꿔 한 번씩 부르고, 확률을 평균해 답을 정한다.
- 객관식 884문항이다. 시험은 2026-09-03에 시행됐다.

## 해석의 한계

- 그림·듣기는 글로 옮긴 입력이다. 자동 검수를 통과한 쪽에도 전사 오류가 남아 있을 수 있다. 점검 후보 61쪽은 `../exams/2027-09/README.md`에 있다. 모든 모델이 같은 입력을 받으므로 비교에는 공통으로 작용하지만, 절대 정확도는 확정치가 아니다.
- 시험 시행(2026-09-03)이 각 모델의 학습 시점 이후라는 가정은 공개 정보로 확인한 것이 아니다. 이 시험이 공개된 지 3주 남짓이라 오염 가능성이 가장 낮은 자료로 골랐다.
- 로컬 모델은 각 프로젝트의 기본 또는 권장 설정을 썼다. 더 큰 체크포인트나 다른 양자화를 쓰면 결과가 달라질 수 있다. 설정 세부는 `shims/<name>/README.md`에 있다.
- CLM은 공식 vLLM 경로 대신 AMD Windows에서 transformers로 임베더를 재현했다. 공식 예시 값과의 비교는 `shims/clm/README.md`에 있다.
- 재실행 변동(PROTOCOL 18, `compare_runs.py`, 태그 `2027-09-rerun`).
  - Laya: 전체 4,225호출이 확률까지 완전히 같았다.
  - SemIf: 무작위 100문항의 rotation 0 호출이 확률까지 완전히 같았다.
  - 로컬 모델은 결정적이다.
  - Jev(API): 같은 요청 4,420회 중 확률이 완전히 같은 호출은 1,216회였다. 고른 보기가 같은 호출은 4,193회(94.9%)였다. 호출당 최대 확률 차이의 중앙값은 0.02, 95백분위는 0.10이다. 보기 순서 5회 평균 뒤 문항 단위 답은 864/884(97.7%)가 같았고, 정답 수는 613 대 611이었다.
  - Jev의 68.2→69.3%는 이 변동 폭 안이므로 보기 순서 평균의 효과로 해석하지 않는다. 순서 평균의 효과가 분명한 쪽은 보기 위치 편향이 큰 open-jev(33.8→40.7%)와 jevmlx(34.6→37.7%)다.
