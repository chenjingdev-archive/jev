# 판 게임 특화 학습 실험 — 사전 고정 (2026-09-30, 학습 전)

## 1. 질문

게임 판단 벤치마크(v1)에서 Jev를 포함한 모든 시스템이 가장 약했던 곳은 판(격자)을 읽는 문항이었다. 판만 주면 Jev도 정확도 37%다. 보기마다 계산된 사실을 붙여 주면 67%로 오른다. 즉 추론보다 판 읽기가 병목이다.

이 실험은 두 가지를 묻는다.

1. 작은 판단 모델(Jeff-0.8B)을 판 게임 문항으로 추가 학습하면, 학습한 게임에서 Jev를 넘는가?
2. 그 능력이 **학습하지 않은 판 게임**으로 옮겨 가는가? 아니면 본 게임의 판만 외우는가?

1번은 Julia(감정 분류)와 Jeff(FPB·RAGTruth)가 이미 보여 준 "학습 분포에서는 이긴다"를 게임에서 다시 보는 것이다. 이 실험의 핵심은 2번이다.

## 2. 데이터 (`build_data.py`)

- **학습 게임 4개:** 지뢰찾기, 미니 스도쿠, 틱택토, 사목.
- **평가 전용 판 게임 4개:** 오목, 오셀로, 미로, 스네이크. 학습에 한 문항도 넣지 않는다.
- 문항은 v1과 같은 게임 생성기(`gamebench/games/`)로 만든다. 시드 범위는 v1(20260927)과 겹치지 않는 1,000,000~1,000,399(학습)와 2,000,000~2,000,019(dev)다.
- **(주석) 문항은 학습에 넣지 않는다.** 보기마다 계산된 사실이 붙은 문항이라, 넣으면 판 읽기가 아니라 주석 읽기를 배운다.
- v1의 `items.jsonl`·`dev.jsonl` 1,144문항과 상황·질문·보기 집합이 같은 문항은 모두 뺀다. 학습과 dev끼리도 겹치지 않는다.
- 게임당 학습 2,000문항(합계 8,000), dev 50문항(합계 200). 파일 해시는 `data/manifest.json`에 있다.

## 3. 학습 (`train.py`)

- **초기 모델:** Jeff-0.8B(`mstrasser/Jeff-Qwen3.5-0.8B`@d66458d), 전체 가중치를 학습한다.
- **손실:** 정답 보기의 교차 엔트로피. Jeff 원래 학습기와 같은 모델 클래스(`jeff.models.load_decision_model`)와 같은 입력 렌더링을 쓴다.
- **설정:**
  - AdamW, lr 1e-5, weight decay 0.01
  - 앞 5% warmup 뒤 cosine
  - 배치 16(4 × 누적 4), 1 epoch(500 스텝)
  - gradient clip 1.0, 시드 20260930
- **계산 장치:** `amd`(Radeon 8060S, ROCm)에서 돌린다. 가중치와 AdamW 상태는 GPU에 fp32로 두고, forward·backward는 bf16 autocast다.
- **체크포인트 선택:** 50스텝마다 dev 손실을 재고, 가장 낮은 체크포인트를 쓴다. v1 문항은 선택에 쓰지 않는다.
- temperature는 원래 체크포인트 값을 그대로 둔다. 답(argmax)에는 영향이 없다.

## 4. 평가

- 채점은 v1 전체 1,064문항을 `gamebench/run.py`로 돈다. 계약과 보기 순환(최대 5회)은 v1과 같다.
- **비교 대상:**
  - **학습 전 Jeff-0.8B를 같은 amd torch 경로로 다시 돌린 결과(`jeff-0.8b-torch`)가 기준선이다.** 원래 v1의 `jeff-0.8b`는 Mac MLX 결과라 장치·백엔드가 다르다. 참고로만 함께 적는다.
  - Jev와 다른 시스템은 v1 기존 결과를 쓴다.

| 묶음 | 문항 | 무엇을 보나 |
|---|---|---|
| A. 학습 게임 | 지뢰찾기·스도쿠·틱택토·사목의 v1 문항 중 (주석) 제외 | 학습 분포 안 |
| B. 새 판 게임 | 오목·오셀로·미로·스네이크의 v1 문항 중 (주석) 제외 | 판 읽기가 옮겨 가나 |
| B′. 새 판 게임의 변형 | B 중 ② 변형 | 새 게임에서 바뀐 규칙까지 읽나 |
| C. (주석) 문항 | 8개 판 게임의 (주석) 문항 | 참고 |
| D. 판 없는 게임 | 나머지 22개 게임 | 원래 능력이 망가지나 |

**가설과 판정 기준 (학습 전에 고정):**
- **H1 (학습 분포):** A에서 학습 후 모델이 기준선보다 많이 맞힌다(같은 문항끼리 McNemar, 양측 p < 0.05). A의 chance-normalized score가 Jev의 A 점수보다 높으면 "학습 게임에서 Jev를 넘었다"고 쓴다.
- **H2 (전이):** B에서 학습 후 모델이 기준선보다 많이 맞힌다(McNemar p < 0.05). 이것이 이 실험의 주 가설이다.
- **D:** 가설 없음. 기준선 대비 점수 변화를 그대로 보고한다.
- 결과가 어느 쪽이든 그대로 쓴다. 판정 기준, 묶음, 체크포인트 선택 규칙은 결과를 본 뒤 바꾸지 않는다. 추가 분석을 하면 "사후 분석"으로 따로 표시한다.
